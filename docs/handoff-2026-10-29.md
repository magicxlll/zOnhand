## 3. Task ĐANG DỞ: T2' (app shell host) — chưa commit, chưa chạy được

Trên đĩa (uncommitted, trong `sim/ebook-emulator/src/emulator/book_reader_emulator.{h,cpp}`):

**Đã viết:**
- `enum class ShellScreen { kHome, kSettings, kReader };` + `ShellState` (home_sel, settings_sel,
  font_size_idx, books, font_dir) — `book_reader_emulator.cpp` ~443-455
- `ScanBooks()` — đọc `.ebook`/`.epub` từ `$EBOOK_LIBDIR` (default `sample`), cũng thử `…/Books`
- `BuildHomeScreen()` (~lấy ~497): title "图书库 · Home", list sách, hint điều hướng
- `BuildSettingsScreen()` (~lấy ~576): chọn 字号 (kFontSizes {20,22,24,25,28,30,34,40})
- Header đã khai báo `book_reader_show_home()` / `book_reader_show_settings()` (chưa có impl)
- Bug đã sửa trong phiên: `std::getenv` → `getenv` (dòng 552); `lv_obj_add_flag(row,
  CLICKABLE|CHECKABLE)` → `lv_obj_add_flag(row, LV_OBJ_FLAG_CLICKABLE)` (LVGL 9.5: hàm nhận
  `lv_obj_flag_t` đơn, không nhận OR của 2 flag)
- Build hiện tại: **pass** (mục home/settings chưa được gọi nên không lộ link error)

**Còn thiếu (chính xác, theo thứ tự):**
1. **Impl `extern "C"`** `book_reader_show_home()` / `book_reader_show_settings()` — gọi
   `BuildHomeScreen()/BuildSettingsScreen()` + set `Shell().screen` tương ứng. Chèn vào block
   `extern "C"` (dòng ~615-819). Kèm helper nội bộ: khi `OpenSessionPath` thành công →
   `Shell().screen = kReader`; khi `set_epdfont_path` gọi từ settings → rebuild reader nếu đang đọc.
2. **Input mode-aware**: callback keyboard trong `book_reader_input_init` (~dòng 641) hiện cứng
   page-turn mọi lúc. Cần nhánh theo `Shell().screen`:
   - **kHome**: `↑/↓` = `sh.home_sel` ±1 (clamp, rebuild list để highlight), `⏎/ENTER` =
     `OpenSessionPath(sh.books[sel])`, `H/ESC` = giữ home.
   - **kSettings**: `↑/↓` = `sh.settings_sel` (cũng là index font, clamp kFontSizeCount),
     `⏎` = `sh.font_size_idx = sh.settings_sel; book_reader_set_epdfont_path(FontPathFor(idx))`
     (hàm này đã tự giữ progress + rebuild reader — xem dòng ~498), `ESC` = về home.
   - **kReader**: giữ mapping T4/T5 (prev/next/home như hiện tại).
   - Rebuild list: hàm `BuildRow` highlight dòng `selected`; đơn giản nhất = gọi lại
     `BuildHomeScreen()/BuildSettingsScreen()` khi sel đổi (hiệu suất không vấn đề, e-paper sim).
3. **Font dir**: `Shell().font_dir` chưa set. Trong `book_reader_input_init()` (hoặc init):
   `sh.font_dir = getenv("EBOOK_FONTDIR") ? ... : "../../../vendor/cloudzao/tools/epdfont/MiSans-Light"`
   (cần kiểm tra relative CWD khi chạy `./run.sh` — an toàn hơn: default tuyệt đối hoặc yêu cầu
   `EBOOK_FONTDIR`; file thật: `misans_20_2.ef`…`misans_50_2.ef`, magic `EPDFONT`).
   `FontPathFor(idx)` đã có (~dòng 487).
4. **Boot**: `main_ebook.c` dòng ~73: hiện `book_reader_init()` (show idle screen) → đổi thành
   `book_reader_show_home()`; nếu có `EBOOK_PATH` (như `run.sh` hiện set) thì giữ hành vi
   `book_reader_open_ebook_path` + set `Shell().screen = kReader`.
5. **Verify**: build (`make -C sim/ebook-emulator/build-ebook ebook_sim -j8`), chạy
   `EBOOK_LIBDIR=<thư mục .ebook>` + `EBOOK_EPDFONT=<path .ef>` (xem `sim/run.sh` mẫu) → home
   hiển thị sách → ⏎ mở → đọc (J/K) → H về… (chưa xác định H về home hay page 0 khi ở home;
   đề xuất: ở kHome, H/ESC là no-op hoặc về home; T2' đơn giản = giữ home). Đổi settings 25→30 →
   render reader to hơn (verify font thật đổi, không phải giả lập).

## 5. Môi trường / mẹo vận hành

- **Build sim:** `cd sim/ebook-emulator && make -C build-ebook ebook_sim -j8` (CMake cache đã
  có; lần đầu: xem `sim/run.sh` có lệnh cmake đầy đủ). `lvgl/` là symlink lên
  `vendor/cloudzao/lvgl` (gitignored, rebuild bằng dòng cuối `sim/ebook-emulator/.gitignore`).
- **Run:** `cd sim && ./run.sh` (không cần env; script tự set `EBOOK_EPDFONT` + `EBOOK_PATH`).
  Hoặc raw: `EBOOK_EPDFONT=vendor/cloudzao/tools/epdfont/MiSans-Light/misans_25_2.ef
  EBOOK_PATH=sim/sample/sample.ebook ./sim/ebook-emulator/build-ebook/bin/ebook_sim -b sdl`
- **Tạo .ebook test:** `cd vendor/cloudzao/tools/ebook && python3 convert_ebook.py a.txt -o b.ebook`
  (đủ module; `epdbook` import OK).
- **Crash debug:** macOS crash report ở `~/Library/Logs/DiagnosticReports/ebook_sim*.ips` (parse
  JSON từ dòng 2; `faultingThread` + `frames`). lldb batch DỪNG (app chạy ~3s rồi crash) — dùng
  crash report thay vì lldb.
- **Git push:** hoạt động nhưng log hiện warning cosmetic `failed to store: -25308` (osxkeychain
  block trong env headless; `credential.helper=store` đã set đúng, token ở
  `.git/.git-credentials-local` — KHÔNG commit file này; gitignore `.git-credentials`).
- **Clangd**: báo `'lvgl.h' file not found` + hàng loạt "unknown type" = **noise** (thiếu
  compile_commands). Nguồn truth duy nhất = `make`.
- **LFS**: font `emulator/assets/fonts/*.ef` upstream là symlink hỏng; font thật ở
  `vendor/cloudzao/tools/epdfont/MiSans-Light/*.ef` (88B = pointer hỏng, >700KB = thật).
